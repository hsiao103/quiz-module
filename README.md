# 知識王遊戲模組

把「防災知識王」的遊戲骨架抽成可換主題的模組：
**一個大螢幕・2–4 位選手・教師遙控・正解只有老師看得到・QR Code 掃描加入・CSV 題庫。**
換名稱、題目、分類，就能變成「XXX知識王」「同樂大挑戰」「校園安全達人」…

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲主程式（不用改） |
| `config.js` | ★ 主題設定：名稱、圖示、顏色、角色名、欄位名稱、網址、規則 |
| `questions.csv` | ★ 預設題庫（Excel／Google 試算表編輯，另存 CSV UTF-8） |
| `peerjs.min.js`、`qrcode.js` | 連線與 QR Code 函式庫（MIT 授權，不用改） |
| `examples/同樂大挑戰/` | 完整範例：換主題只要複製 `config.js` 與 `questions.csv` 蓋過去 |

## 三步驟做出新遊戲
1. **複製整個資料夾**，取新名稱（例如 `challenge`）。
2. 編輯 `config.js`：至少改 `title`、`icon`、`storageKey`（★每個遊戲請用不同英文代號）。
3. 編輯 `questions.csv`，上傳到 GitHub Pages（或任何靜態網站）。
   網址就是遊戲網址，大螢幕的 QR Code 會自動使用該網址。

> 不想動檔案也可以：進入「主持人」頁面最下方「題庫管理」直接上傳 CSV（保存在這台電腦的瀏覽器）。

## config.js 重點
- `title` / `icon` / `subtitle`：遊戲名稱、圖示、首頁說明
- `stageSuffix`：大螢幕標籤結尾，如「競賽」「挑戰」「大賽」
- `theme`：顏色，例如 `{acc:'#22c55e'}`
- `characters`：四位選手角色的名稱
- `labels`：篩選欄位名稱，例如 `{lv1:'組別', lv2:'關卡', cat:'主題'}`；`lv1Suffix`：年級後綴（非年級用途請改成 `''`）
- `tierOrder`：第二層（難度／關卡）的顯示順序
- `csvUrl`：預設題庫檔名（預設 `questions.csv`）
- `storageKey`：★ 每個遊戲唯一的代號；`publicUrl`：QR Code 網址（上線後可留空）
- `pointsBase` / `pointsSpeed` / `defaultN` / `defaultLimit`：計分與預設題數、秒數

## CSV 格式
`年級,難度,類別,題型,題目,正解,錯誤1,錯誤2,錯誤3,解析`（欄位名稱可改成 config 的 `labels`，也可用「組別／關卡／主題」）
- 選擇題：正解 + 錯誤1～3（共 4 個選項，自動洗牌）
- 是非題：題型填「是非」，正解填 ○ 或 ✕（或 對／錯）
- 第一欄「年級／組別」與第二欄「難度／關卡」用來分組與篩選，可留白
- 格式有誤或重複的題目會被略過並列出原因
- 用 Excel 存檔時請選「CSV UTF-8（逗號分隔）」；Big5 編碼也能自動辨識

## 執行流程
主持人建立房間 → 大螢幕（顯示 QR Code）→ 選手掃描加入 → 篩選題庫 → 出題 →【結算】→【公布】→ 下一題。
空白鍵＝依序推進，P＝暫停。

## 注意
- 本機直接開啟 `index.html`（file://）時瀏覽器不允許讀取 `questions.csv`，請放到網站上，或用主持人頁的 CSV 上傳。
- 跨裝置連線使用 PeerJS 公用雲端服務，現場請先實測。
- 同一個網站放多個遊戲時，每個遊戲的 `storageKey` 必須不同。

## 佈景主題

主持人控制台的「🎨 佈景主題」可隨時切換，大螢幕與選手手機會即時同步：

- 🧱 **樂高風**（預設）
- ⛏️ **麥塊風**：泥土／草地方塊背景、斜角石頭按鈕、綠色經驗條，角色頭像變成方塊像素
- 👾 **像素風**：8-bit 復古配色、缺角像素邊框、掃描線，角色頭像變成像素圖

上次選的主題會記在這台電腦，下次開啟自動套用。像素字型（DotGothic16、Press Start 2P）會在切換到這兩個主題時才從 Google Fonts 載入；連不上網路時會改用系統字型，功能不受影響。
